NewApiBar

页面设计系统 v1.0 — 深色 / 浅色双主题
项目说明：NewApiBar 是一个 Electron 桌面浮窗，用于实时监控 New API 面板的余额、今日消耗和模型用量排行。 窗口尺寸约 260×450px，支持拖拽标题栏移动、边缘缩放、毛玻璃背景、透明度调节。
